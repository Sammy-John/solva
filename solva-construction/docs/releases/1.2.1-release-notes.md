# Release 1.2.1 Notes

Release 1.2.1 focuses on schedule export reliability and a more readable client handoff file.

## Highlights

- Added formatted Excel export as the primary schedule export option.
- Excel workbooks include `Schedule`, `People`, and `Attention` sheets.
- Added an export success message with the generated filename and Downloads-folder guidance.
- Improved Excel workbook presentation with a title, autofilter, wider key columns, wrapped cells, borders, and status/attention highlighting.
- Schedule exports now include task type, status, dates, duration, assigned names, Waiting On dependency details, and comments.
- CSV export remains available as a simple fallback.
- Moved export row-building into a tested library so CSV and Excel share the same schedule data.

## Verification

- `npm run test`
- `npm run build`
- `npm run release:alpha:test`
- `npm run release:manifest:test:github -- --notes "Test release 1.2.1 - Excel export feedback and formatting"`

## Notes

- The Excel export uses `exceljs`, which increases the production bundle size. The build currently completes with Vite's standard large chunk warning.
- People data is exported from the existing project-level people list. The master People directory upgrade remains deferred to 1.2.2.
